# dark-forge.dev deploy of Kiln v0.4.11

Record of the deploy of dark-forge.dev from Kiln 0.4.10 to the published release v0.4.11. The annotated tag `v0.4.11` points at commit `e29f26a68d88bfc38e240ae6278c0ccaf2ea9fb7` on main. Jamie approved this deploy, including the one-way identity schema migration from #51. Assets came only from `https://github.com/Jabbslad/kiln/releases/download/v0.4.11/`. Each downloaded asset was checked with its `.sha256` sidecar before use. `releases/latest` was not used. `authorized_keys` was not edited. `/var/lib/kiln-api` was not moved or deleted. No admin token was copied off the host.

Result: **PASS**. Rollback was not executed.

The release `install.sh` is the bootstrap. It pins `version=0.4.11` and the server archive digest, and it does not accept `--dashboard-archive`. The upgrade that ran is the inner `install.sh` from the verified server archive, which is the command in `docs/runbooks/2026-10-20-app-dark-forge-caddy.md`:

```sh

```

That command printed `Updated to Kiln 0.4.11. Host admin API: https://127.0.0.1:8443`. It did not print `Ready:`. It did not print `attestation=verified`.
